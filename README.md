# Hotel API

Une API RESTful permettant de mettre en place un système de réservation d'un hôtel.

---

## Technologies utilisées

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)

---

## Installation

1. **Cloner le dépôt :**
-  git clone https://github.com/ConstantKOUASSI12/hotel-api.git
-  cd hotel-api

2. **Installer les dépendances :**
-  npm install

3. **Créer un fichier .env à la racine :**
-  PORT=3000
-  NODE_ENV=development

5. **Lancer le serveur en développement :**
-  nodemon index.js

6. **Lancer le Swagger UI route :**
-  http://localhost:3000/api-docs
